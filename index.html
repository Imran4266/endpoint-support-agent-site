What it does

Built for everyday endpoint issues

The agent combines local troubleshooting knowledge, MCP tools, model selection, and approval-gated remediation so helpdesk teams can move from symptom to safe action faster.

01

Conversational triage

Users can describe issues in normal language: slow system, broken camera, Outlook sync, printer queue, VPN, updates, and more.

02

MCP hybrid routing

Routes requests through local MCP tools for diagnostics, remediation, knowledge lookup, model control, and endpoint actions.

03

Approval-first fixes

Every endpoint-changing action asks for explicit approval, displays risk, and records audit information.

04

OEM driver workflow

Detects Dell, HP, Lenovo, or Surface paths and uses OEM utilities for trusted driver updates instead of random driver packages.

05

Application repair

Supports common repair paths for Teams, Outlook, OneDrive, Office, browsers, Adobe Reader, Citrix, Slack, Zoom, and Webex.

06

Plain-language output

Summaries are written for non-IT users, while technical details remain available when support engineers need raw output.

Install

Set up on a Windows endpoint

  1. Download EndpointSupportAgent-Setup.exe.
  2. Run the setup file — it will automatically install Python and Node.js if not already present.
  3. Launch the agent from the created shortcut and paste your API key when prompted.

Requirements

  • Windows 10 or Windows 11 endpoint
  • Internet access for setup and AI model communication
  • Python and Node.js are installed automatically if missing
  • Installs to C:\Program Files\EndpointSupportAgent
  • Runs with Administrator privileges for full system access
  • Uninstall via Control Panel → Programs and Features
